# SPECTER-S3
Tool portatile ESP32 con RFID, log e display
SPECTER-S3 è un firmware per ESP32-S3 pensato per trasformare una semplice scheda con OLED, tasti e lettore RFID in un vero dispositivo portatile multifunzione. L’interfaccia su display permette di navigare tra menu chiari e veloci, gestire file salvati nella memoria interna, analizzare segnali audio in tempo reale e leggere/salvare UID delle tessere RFID tramite il modulo MFRC522.

Il sistema integra un file manager su LittleFS, funzioni di logging persistente, screen sleep intelligente, gestione avanzata dei pulsanti con debounce ottimizzato e una UI fluida pensata per essere usata senza computer. È progettato per stare in un case stampato in 3D, compatto e robusto, diventando uno strumento tascabile ideale per test, sperimentazione elettronica e sviluppo embedded.

SPECTER-S3 unisce controllo hardware, gestione dati e visualizzazione su display in un’unica esperienza, offrendo un ambiente modulare, espandibile e completamente personalizzabile per chi vuole portare l’ESP32 oltre il semplice prototipo da banco. CONTIENE TOOL DI HAKING AVANZATO
